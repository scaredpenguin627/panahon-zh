# 华为天气主界面视频证据

来源：`C:\Users\Admin\Downloads\天气页面.mp4`。

- 视频分辨率为 890×1920，时长约 12.09 秒。按 2 fps 采样后，画面表现为同一城市天气页的连续上下滚动。
- 页面采用全屏蓝色渐变和天气背景，卡片为半透明深蓝色圆角面板；顶部导航保持固定。
- 顶部导航从左到右为三横线菜单、居中的城市名称、放大镜搜索、四点更多菜单。滚动后城市标题下方收缩显示当前温度和天气。
- 首屏顺序为：当前天气英雄区、高温橙色预警卡、逐小时预报横向滚动卡、多日预报卡。
- 多日预报包含星期、绝对日期、天气图标、天气文字、高低温趋势曲线和空气质量等级，并提供“查看更多天气”。
- 继续向下为 AQI 卡、台风/紫外线卡、穿衣/体感/风/湿度/日落卡、过敏/钓鱼/能见度/感冒卡、天气地图预览、气压和其他指数。
- 页面底部包含天气预报插图、更多指数横排、气象专题横幅和版本版权。

建议的 clean-room 实现测量（以 890 px 画布为基准）：

- 内容左右边距约 36 px，卡片间距约 12–16 px，圆角约 18–22 px。
- 英雄区城市名中心约 y=270，当前温度字号约 96–110 px；高低温和天气描述字号约 26–32 px。
- 首屏卡片宽度约 818 px；小时卡每个单元约 150–165 px，保留横向滚动。
- 多日卡保留 5 列左右可见，左右边缘渐隐提示可继续横向滚动。
- 生活指数采用两列网格；天气地图和气象专题为整宽卡片。
