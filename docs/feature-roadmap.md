# 功能范围和发布记录

本文件记录 `panahon-zh` 当前版本的范围。阶段 3 的 B、C、D 组已经明确排除，不作为下一步任务。若以后重新纳入，必须重新确认数据源、平台能力、许可和测试条件。

## 当前版本已完成

当前版本保留阶段 3 A 组核心功能：

- 天气首页、当前天气、逐小时预报和五日预报。
- AQI 摘要、PM2.5/PM10 AQI 子指数和其他污染物的明确不可用状态；监测站、趋势和历史代码保留，但属于当前版本排除范围。
- 降水雷达和时间轴；卫星、闪电、台风、灾害、温度和风力适配器代码保留，但属于当前版本排除范围。
- 预警列表、地点和全国范围过滤、有效期、官方正文和原文复制。
- 城市搜索和单地点选择；Android 地点持久化代码保留，当前云端和真机未验证。
- 中文和 English 切换。
- 来源、更新时间、质量、加载、缓存、错误和不可用状态。
- 首页、AQI、地图、预警和设置之间的导航。
- 七项数据可信度门槛：降水缺失、热指数质量、Manila 时区日期、未知图标、生活指数输入、来源/更新时间和跨模块质量状态。
- Blender 5.3 原创云天空原型。运行时由 egui 负责动态数据和回退动画。

## 数据和离线要求

每个功能都必须记录数据来源、更新时间、许可范围和离线行为。运行时数据来自 PAGASA、DENR-EMB、Open-Meteo 或 CAMS 时，页面保留来源和质量标签。模型数据不标为官方观测，缺少字段不填入 0。预警正文保留官方原文，复制动作不改写正文。

网络请求在后台线程执行。刷新失败时保留最近一次可信缓存，没有缓存时显示空状态。`PANAHON_DEMO=1` 才使用内置样例。Android 本地记录不能冒充连续官方监测。

## 当前明确排除范围

以下项目不属于当前版本：

- 15 日、90 日、月度和长期预报。
- 霞光地图、霞光打卡点、月相、月距和完整健康、过敏、防晒、感冒指数。
- 温度和风力地图适配器、完整台风底图、完整风圈和自动站地图。
- 桌面小组件、负一屏、系统桌面集成和系统级后台通知。
- 专有天气视频播放、天气助手、语音查询、资源下载和空间感天气资源。
- Huawei 账号、云空间、钱包、系统推送和其他专有后台服务。
- 复制 Huawei 服务条款、隐私正文、字体、图片、商标或其他专有资源。

Blender 只用于原创视觉原型或离线资源。实时天气、AQI、预警和地图帧不能烘焙成不可更新的视频。

## 重新纳入条件

如果产品范围发生变化，先补充一份范围决策，至少说明：

1. 数据源、字段、更新时间和缺失状态。
2. Android、桌面或其他平台能力。
3. 许可、原创资源和包体限制。
4. 离线行为、错误状态和测试设备。
5. 是否需要新的 Blender 原型，以及 egui 回退方案。

在这些条件确认前，排除项目不进入路线图，也不在 README 中写成已支持功能。
