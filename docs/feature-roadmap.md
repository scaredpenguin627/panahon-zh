# 功能扩展路线

“知天气”提供了天气预报、空气质量、雷达和卫星云图、台风路径、预警中心、生活指数和旅游气象等功能。相关功能来自[知天气 App Store 页面](https://apps.apple.com/mo/app/%E7%9F%A5%E5%A4%A9%E6%B0%94/id451961462)和[福建省气象局介绍](http://fj.cma.gov.cn/xwzx/tpxw/202309/t20230927_5804176_ext.htm)。

PANaHON 已经提供地点、实时天气、逐小时和五日预报、地图入口和预警入口。PAGASA 官网还公开了自动站、人工站、雷达、卫星、闪电、洪水风险和风暴潮等数据类别，见[PAGASA 官方站点](https://www.panahon.gov.ph/)。

## 第一阶段

这些功能可以直接接入现有 Rust 数据模型：

- 保存地点、地点搜索和当前地点切换。
- 实时观测卡片，显示温度、体感、湿度、气压、风和降雨。
- 逐小时预报、五日预报和城市展望。
- 预警详情、影响区域和防御建议。
- 本地通知。通知由 Android 本地调度器触发，不依赖 FCM。当前支持 1 分钟测试调度和每 30 分钟的进程内提醒。

## 第二阶段

这些功能需要增加地图图层和缓存：

- PAGASA 雷达拼图和 Himawari 卫星云图的最新帧。
- 雷达和卫星时间轴播放、缩放和图层叠加。
- 台风路径、风圈和预计登陆区域。
- 自动站、人工站和历史观测趋势。
- 降雨、温度、风、湿度和热指数图层。
- 洪水、风暴潮和灾害风险图层。

## 第三阶段

这些功能需要额外的数据许可和接口：

- 空气质量和污染物趋势。
- 旅游景点未来一周天气。
- 生活指数。
- 语音播报和天气科普内容。

每个新增模块都要记录数据来源、更新时间、许可范围和离线行为。GrapheneOS 的 Network 权限关闭时，应用继续显示缓存或样例数据；用户打开 Network 权限后，应用再请求公开接口。

当前空气质量中间服务位于 `services/emb-aqi/`。它读取 DENR-EMB 的公开 Power BI 报表，默认缓存 5 分钟。部署前仍需确认 DENR-EMB 对接口调用、缓存和再分发的授权范围，并为公网部署配置 HTTPS。

App 未配置 `PANAHON_AQI_ENDPOINT` 时，会调用 Open-Meteo 的 Air Quality API。这个备用接口返回 CAMS 预测数据，页面会显示“Open-Meteo / CAMS”，并保留数据来源链接和归因说明。

地图服务读取 PAGASA 首页返回的短期 CSRF 令牌，再调用公开的雷达、Himawari、闪电、台风和 CAP 预警接口。令牌只在内存中使用，不写入 APK 或日志。接口字段变化时，地图页保留官方交互地图入口。
